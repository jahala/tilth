Read code as a tree.

the structure under the surface.

tilth is code intelligence for AI agents and the people who work with them. It parses your code and answers what text search can't: where a symbol is defined, who calls it, what a file depends on, and what changed, function by function. One binary, on the command line and as an MCP server, with no index to build.

why

Six calls to find one function.

tilth began with watching agents make six tool calls to find one function: list the files, read one, find it too big, search for a word, read again, read another. An agent with text search finds where a word appears. To learn who calls a function it has to read files and work the answer out, and that answer can be wrong without anyone noticing. tilth parses the code and computes the answer.

what it answers

  • where it is defined
  • who calls it
  • what it calls
  • what a file depends on
  • what changed, function by function
  • the outline of a file too big to read

the commands

One question per command

  1. 1

    tilth <path>

    reads a file whole, or as an outline with line ranges once it passes about 6,000 tokens. --section 45-89 returns just those lines.

  2. 2

    tilth <symbol>

    finds the definitions first, then the usages, each shown among the symbols around it.

  3. 3

    tilth <symbol> --callers

    lists every call site, matched on the syntax tree, so comments and strings that mention the name are left out.

  4. 4

    tilth grok <symbol>

    returns everything about one symbol in one call: signature, doc comment, body, callees, callers, siblings and tests.

  5. 5

    tilth <path> --deps

    shows what a file uses and what uses it, down to the symbol. Read it before you rename an export.

  6. 6

    tilth diff HEAD~1

    reports a change per function: what was added, what was removed, and whether a signature or only a body changed.

And text, regex and glob search, --expand to inline the source of the top matches, and --map for a skeleton of the codebase. An agent gets the same engine as MCP tools (search, read, list, deps, grok and diff, plus write in edit mode), and tilth remembers what the agent has seen, so a definition already shown is not sent twice.

what it doesn't do

  • typestilth parses syntax. It does not resolve types.
  • same namesCallers and dependencies are matched by name, so two functions with one name in different modules look alike, and dynamic dispatch is out of reach.
  • other languagesA language without a grammar in tilth gets text search and plain reading only.

tilth parses 17 languages: Rust, TypeScript, TSX, JavaScript, Python, Go, Java, Scala, C, C++, Ruby, PHP, C#, Swift, Kotlin, Elixir and Bash. It parses with tree-sitter and searches with ripgrep’s own engine.

Install

One binary with no runtime dependencies, from crates.io or npm. Prebuilt binaries are on the releases page.

cargo install tilth
# or
npx tilth

Then tilth install <host> adds it to your agent host's MCP config, and --edit adds hash-anchored editing.

It knows 23 hosts, among them claude-code, codex, gemini, cursor, vscode and zed, and the README lists them all. Any other MCP client runs tilth --mcp.

Smaller models sometimes reach for their built-in tools anyway. In Claude Code, claude --disallowedTools "Bash,Grep,Glob" makes tilth the only route. The agent prompt is in AGENTS.md, and a Claude Code skill in skills/SKILL.md.
