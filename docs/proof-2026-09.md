# Output parity proof — the tilth-core split, September 2026

**Claim.** Turning tilth into a Cargo workspace (`tilth` binary + `crates/tilth-core` library) changed no behaviour: the binary built from the workspace produces the same bytes as the v0.10.1 release binary, over a fixed matrix of CLI commands and MCP sessions on the benchmark fixture repos.

**How it was measured.** `scripts/check/output-parity.sh` builds v0.10.1 from its tag, builds the candidate from this tree, and runs both over the same 32 cases per fixture repo (ripgrep, fastapi, gin, express at the commits `benchmark/config.py` pins): file reads (outline, section, full, JSON, budget, markdown), symbol, content, regex, multi-symbol and glob-filtered searches with and without expansion, callers, deps, glob, map, grok, structural diff and diff log, the project fingerprint, two error paths, and four MCP sessions over stdio (read-only and edit mode, each with and without the project fingerprint) exercising every advertised tool including a `tilth_write` that must refuse on a bad hash anchor. stdout, stderr, and exit code are compared together. The reference runs three times, the candidate twice, with `TILTH_THREADS=1`.

**Result.** 128 cases: 118 byte-identical; 10 identical modulo list order; 0 mismatches.

**The ten modulo-order cases are v0.10.1's own nondeterminism, not a change.** In each, the three reference runs disagree with each other: the project fingerprint's `dirs:` and hot-file lists come out of a hash map in varying order (visible in `overview` and inside the `initialize` response of MCP sessions that carry the fingerprint), and `tilth diff` / `tilth diff --log` list a file's changed symbols in varying order. For those cases the outputs are compared with commas and JSON newline escapes treated as separators, each line's tokens sorted, and lines sorted; the candidate matches every reference run under that normalisation, and the same cases with the fingerprint suppressed (`TILTH_NO_OVERVIEW=1`) are byte-identical. The nondeterminism is on `main` today and is out of scope for a zero-behaviour-change split; the determinism fix in PR #196 (commit a3a2d04) addresses the search walker, and the fingerprint leaves the `initialize` payload with the context diet.

**Test suite.** v0.10.1 ran 654 tests (650 in the library target, 4 in the binary). The workspace runs the same 654 (456 binary + 4 binary + 193 in `tilth-core`, one file at a time), plus 9 new acceptance tests in `crates/tilth-core/tests/api.rs` for the negotiated public surface. No test was deleted, weakened, or ignored. One test changed its fixture: `overview::tests::test_fingerprint_on_tilth` now fingerprints `crates/tilth-core` instead of the repository root, because the root is a workspace whose Rust sources sit below the fingerprint's depth-2 walk and the benchmark's Python outnumbers what the walk can see; both the v0.10.1 and the workspace binary print the same fingerprint for the root, so this is the repository's shape changing under a fixed function, not the function changing.

**Reproduce.** `bash scripts/check/output-parity.sh` (builds the reference from the tag; needs the fixture repos, which `benchmark/fixtures/setup_repos.py` clones). The run below was taken on this branch before its commit; the tree measured is the tree this document is committed with.
